# Fairy Magic Trail

A cosmetic RuneLite plugin that adds small pastel sparkles around your character while moving.

## Features

- Small pastel sparkles in pink, purple, blue, and white.
- Small sparkles that float and fade away over time.
- Configurable sparkle size and lifetime.
- Lightweight cosmetic visual effects.

## Installation

Once approved and published, search for Fairy Magic Trail in the RuneLite Plugin Hub and install it.

## Development

## Development

Build on Windows:

`.\gradlew.bat build`

Run the development client:

`.\gradlew.bat run`
